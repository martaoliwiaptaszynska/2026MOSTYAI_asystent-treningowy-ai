O projekcie

Prototyp aplikacji AI wspierającej użytkownika w analizie danych treningowych ze Stravy i generowaniu spersonalizowanego planu treningowego na kolejny tydzień. Projekt zrealizowany w metodologii MOSTY AI.

Model AI: gemini-2.5-flash  |  Stack: Python + Streamlit  |  Dane: Strava API

Wymagania

  • Python 3.9 lub nowszy
  • Konto Strava z historią aktywności
  • Klucz Strava Developer API (strava.com/settings/api)
  • Klucz Gemini API, model gemini-2.5-flash (aistudio.google.com/apikey)
⚠ WAŻNE: Darmowy tier Gemini API pozwala na 5 zapytań/min i ok. 25 zapytań/dzień. Odczekaj chwilę między kolejnymi analizami. Jeśli pojawi się błąd 429 — poczekaj 30 sekund i spróbuj ponownie.

Jak uzyskać klucze API

🚴 Strava API

  1. Wejdź na strava.com/settings/api
  2. Utwórz aplikację (nazwa dowolna, callback: localhost)
  3. Skopiuj Client ID i Client Secret
  4. Autoryzuj aplikację przez URL:
    https://www.strava.com/oauth/authorize?client_id=TWOJ_ID&response_type=code&redirect_uri=http://localhost&approval_prompt=force&scope=activity:read_all
  5. Z adresu po przekierowaniu skopiuj parametr code=...
  6. Wymień kod na Refresh Token komendą w terminalu:
    curl -X POST https://www.strava.com/oauth/token -d client_id=ID -d client_secret=SECRET -d code=KOD -d grant_type=authorization_code
  7. Skopiuj wartość refresh_token z odpowiedzi

🤖 Gemini API

  1. Wejdź na aistudio.google.com/apikey
  2. Zaloguj się kontem Google
  3. Utwórz nowy projekt i kliknij Create API Key
  4. Skopiuj klucz — wymagany model: gemini-2.5-flash

Funkcjonalności

  • Pobieranie historii aktywności ze Strava API (ostatnie 4 tygodnie)
  • Analiza AI: poziom aktywności, postępy, ryzyko przeciążenia, słabe punkty
  • Generowanie planu treningowego na 7 dni dopasowanego do celu użytkownika
  • Obsługa błędów API (W1: błędny token, W2: brak danych, W3: błędny klucz Gemini)
  • Guardrail: odrzucanie celów niesportowych
  • Pobieranie raportu jako plik TXT
  • Ciemny motyw z pomarańczowymi akcentami
⚠ PRYWATNOŚĆ: Aplikacja nie zapisuje żadnych danych. Klucze API i dane treningowe są aktywne tylko podczas sesji i nie są logowane ani przechowywane.
